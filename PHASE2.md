## 1. What was built (`src/extract/`, ~2,100 lines of Zig incl. tests; every file < 600 lines)
| File | What |
|---|---|
| `allow.zig` | The only two endpoints: `127.0.0.1:18080` (glm-5.3-flash, thinking off) and `127.0.0.1:18033` (glm-5.3, nothing extra sent, never `reasoning_effort`). IP literals, no DNS. `resolve()` refuses everything else (18 refusal cases tested). |
| `llm.zig` | OpenAI-compatible non-stream client on raw Linux sockets (phase-0 pattern, TCP_NODELAY, SO_RCV/SNDTIMEO). `permitted()` is re-checked immediately before every `connect()`. Counts connects / refusals / canary strings seen in any request body. temperature 0, seed 7. |
| `prompts.zig` | Our own extraction + dedup prompts (version `x2.1`; sha256 stamped on every row). Turns rendered as DATA inside `<turns>`; `escapeData` neutralises `<…` tags, `<\|`/`\|>` and fake `[id]` line headers so a turn cannot close the block or forge a role. |
| `parse.zig` | Bounded JSON recovery (after `</think>`, ≤32 balanced-brace candidates, ≤256 KB, string-aware) + a strict validator: exact keys, type enum, priority 0–100, `valid_from` YYYY-MM-DD/null, `turns` ⊆ the NEW ids shown, third-person text that names its subject (refuses "User has…", "I …"). Dedup decisions: one per memory, and `target` must be one of that memory's own candidate ids (SPEC §1.3). |
| `people.zig` | Attribution: model subject → household id/alias. `unknown`/`user`/`speaker`/… → `pending_review`; names outside the household list keep their name and go `pending_review`; a text that does not name the resolved subject → `pending_review`. Nothing defaults to Alex. |
| `chunk.zig` | Tokenizer-free split (byte budget, sentence snapping, UTF-8 safe, 300-byte overlap) + warm-up scheduler 1→2→4→N with idle flush (unit-tested: fires at turns 1, 3, 7, 12, 17…). |
| `sink.zig` | The narrow interface: `insert / supersede / demote / findSimilar`. **No delete exists in it.** `MemSink` for offline tests; a source-scan test fails the build if a delete/drop/remove call appears anywhere in `src/extract/`. |
| `store_sink.zig` | The Sink on the phase-1 store (`atoms.insert / supersede / setStatus(retired)` + audit / `search`). Provenance → `extractor` (`zigmem-extract/x2.1\|model\|p:x2.1`), `prompt_sha`, `run_id`, `src_l0` (`turn=N sha=<sha256 of the stripped turn>`). Candidates = BM25 top-20 filtered to ≥2 shared content words. **Wired: every gate run below wrote through the real store.** |
| `pipeline.zig` | Turn → `<private>` strip (the store's port; fail-closed: a filter error drops the turn, not even kept as context) → user turns only (assistant text = context) → chunk → extract → validate → **one repair retry** → attribute → candidates → exact duplicate skipped in code → batch judge (+1 repair) → apply: `store` insert · `supersede` (same subject only; old row `superseded` with `valid_to`, creation time kept) · `correct` (new row + old row demoted to `retired` with a pointer) · `skip`. A failed judge or a failed reply never writes `active` and never touches an old row: rows land `pending_review`. |
| `gate.zig` | `zigmem-extractgate` (`zig build extractgate --release=safe`): runs the set, prints JSON lines (turn logs, every row, summary). |
| `pipeline_test.zig` | Offline stub-engine tests: the Morgan→Alex tires correction, private canaries never in a request, invalid-twice → no active row, a judge naming an out-of-set id cannot touch any row, exact dup skipped with no judge call. |

Build: one additive block in `build.zig` (`test-extract`, `extractgate`; the store reached as its own module). Tests: `tests/extract/make_turns.py` (set), `grade.py`, `run_gate.sh` (strace + ss audit + grade).
